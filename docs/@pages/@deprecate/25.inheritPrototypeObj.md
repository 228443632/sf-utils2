::: note 描述
寄生式继承，本质上其实和 [Object.create](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Global_Objects/Object/create) 方法没有区别，这里主要是为了兼容的方式去完成继承
:::

## 1.示例

```js
import { inheritPrototypeFromObj } from '@bianpengfei/utils'

const vuePrototype = {
  sayHello: () => {
    alert('sayHello')
  }
}
const vueInstance = Object.assign(
  {
    version: '2.0.0',
    data() {},
    mounted() {}
  },
  vuePrototype
)
const _inheritVueInstance = inheritPrototypeFromObj(vueInstance)
console.log(_inheritVueInstance)
```

## 2.入参说明

| 参数      | 说明      | 类型     | 是否必填 | 默认值 |
| --------- |---------| -------- | -------- | ------ |
| prototype | 继承的原型对象 | `Object` | 是       | {}     |

## 3.源码

::: details 源码，点开查看 👈

```js
/**
 * 寄生式继承
 * @param {Object} prototype 原型对象
 * @returns {any}
 */
function inheritPrototypeFromObj(prototype = {}) {
  let createFn = Object?.create
  if (!Object?.create) {
    createFn = obj => {
      const F = function () {}
      F.prototype = obj
      return new F()
    }
  }
  return createFn(prototype)
}
```
