::: note 描述
给 dom 添加 class，为了兼顾 ie，因为 低版本 ie 不支持 el.classList。 <br/>
支持批量添加 class， 空格隔开
:::

## 1.示例

::: demo

```vue
<template>
  <div>
    <el-divider content-position="left">推荐打开控制查看 dom元素节点</el-divider>

    <el-button type="primary" @click="bodyAddClass('theme', $event)">给body添加 theme 类</el-button>
    <el-button type="primary" @click="bodyAddClass('theme-mode', $event)">给body添加 theme-mode类</el-button>
    <el-button type="primary" @click="bodyAddClass('body-class=1 body-class-2', $event)"
      >给body添加多个类 body-class=1 body-class-2</el-button
    >
  </div>
</template>

<script>
import { addClass } from 'sf-utils2'
export default {
  methods: {
    bodyAddClass(cls = '', event) {
      addClass(document.querySelector('body'), cls)
      this.$message.success(`${event.target.innerText}添加成功，请打开控制台查看dom节点`)
    }
  }
}
</script>
```

:::

::: warning ⚠️ 注意
当添加多个 class 类时，需要以空格隔开，比如添加两个类，class-1 和 class-2， 这时候传值 class 是<br/>
`class-1 class-2`
:::

## 2.入参说明

| 参数 | 说明     | 类型          | 是否必填 | 默认值 |
| ---- | -------- | ------------- | -------- | ------ |
| el   | dom 元素 | `HTMLElement` | -        | -      |
| cls  | class 名 | `String`      | -        | -      |

## 3.源码

::: details 源码，点开查看 👈

```js
/**
 * dom元素添加类名
 * @param {HTMLElement} el dom元素
 * @param {string} cls 类名
 */
function addClass(el, cls) {
  if (!el) return
  let curClass = el.className
  let classes = (cls || '').split(' ')

  for (let i = 0, j = classes.length; i < j; i++) {
    let clsName = classes[i]
    if (!clsName) continue

    if (el.classList) {
      el.classList.add(clsName)
    } else {
      if (!this.hasClass(el, clsName)) {
        curClass += ' ' + clsName
      }
    }
  }
  if (!el.classList) {
    el.className = curClass
  }
}
```
