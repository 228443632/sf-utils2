::: note 描述
判断 dom 是否含有某个 class，为了兼顾 ie，因为 低版本 ie 不支持 el.classList
:::

## 1.示例

::: demo

```vue
<template>
  <div>
    <el-button type="primary" @click="judgeBodyHasClass('theme', $event)">判断body是否包含 theme 类</el-button>
    <el-button type="primary" @click="judgeBodyHasClass('theme-mode-light', $event)"
      >判断body是否包含 theme-mode-light 类</el-button
    >
    <el-button type="primary" @click="judgeBodyHasClass('theme-mode', $event)">判断body是否包含 theme-mode类</el-button>
  </div>
</template>

<script>
import { hasClass } from 'sf-utils2'
export default {
  methods: {
    judgeBodyHasClass(cls = '', event) {
      const flag = hasClass(document.querySelector('body'), cls)
      alert(`${event.target.innerText}：${flag ? '包含' : '不包含'}`)
    }
  }
}
</script>
```

:::

## 2.入参说明

| 参数 | 说明     | 类型          | 是否必填 | 默认值 |
| ---- | -------- | ------------- | -------- | ------ |
| el   | dom 元素 | `HTMLElement` | -        | -      |
| cls  | class 名 | `String`      | -        | -      |

## 3.源码

::: details 源码，点开查看 👈

```js
/**
 * 查看元素是有包含class
 * @param {HTMLElement} el 元素
 * @param {string} cls class类名
 * @returns {boolean}
 */
function hasClass(el, cls) {
  if (!el || !cls) return false
  if (cls.indexOf(' ') !== -1) throw new Error('className should not contain space.')
  if (el.classList) {
    return el.classList.contains(cls)
  } else {
    return (' ' + el.className + ' ').indexOf(' ' + cls + ' ') > -1
  }
}
```
