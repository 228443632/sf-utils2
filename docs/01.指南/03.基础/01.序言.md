::: note 描述
核心 🍺，这一块主要是对 数据进行校验，主要对数据结构进行转化，一些常见的树状结构转成 list，或者 list 转成 tree 树状结构
:::

### npm 使用方式

```js
import BUtils, { uuid } from '@bianpengfei/utils'

// 方式1
BUtils.uuid()

// 方式2
uuid()
```

::: danger 提示
不推荐使用 解构函数， 因为会里面逻辑大量用了 this，如果解构了，this 会导致指向错误问题
:::

### cdn 使用方式

```html
<script src="https://cdn.jsdelivr.net/npm/@bianpengfei/utils/lib/b-utils.min.js"></script>
<script>
  window.BUtils.uuid()
</script>
```
