::: note 描述
防抖函数
:::

## 1.示例

```js
import { debounce } from '@bianpengfei/utils'

const resizeFn = e => {
  console.log('滚动了', e.target)
}

const debounceResize = debounce(resizeFn, 400) // 距离上次执行间隔时间400ms，以最后一次运行为基准

window.addEventListener('resize', debounceResize, false) // 开始监听

window.removeEventListener('resize', debounceResize, false) // 卸载监听
```

## 2.入参说明

| 参数 | 说明                           | 类型       | 是否必填 | 默认值        |
| ---- | ------------------------------ | ---------- | -------- | ------------- |
| fn   | 回调函数                       | `Function` | 是       |               |
| wait | 距离上次执行间隔时间，单位毫秒 | `Number`   | 否       | 默认 800 毫秒 |

## 3.源码

```js
/**
 * 防抖函数
 * @param {function} fn 回调函数
 * @param {number} wait 等待时间，默认值是300毫秒
 */
function debounce(fn, wait = 300) {
  let timer = null
  return function () {
    let args = arguments
    clearTimeout(timer)
    timer = setTimeout(() => {
      fn.apply(this, args)
    }, wait)
  }
}
```
