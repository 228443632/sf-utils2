## 1.示例

### 1.1 formatSizeUnit(arg = ''') 格式化尺寸
```javascript
import { formatSizeUnit } from '@bianpengfei/utils'

formatSizeUnit('100vh') // 100
formatSizeUnit('90vw') // 90
formatSizeUnit('100px') // 100
formatSizeUnit('80.1rem') // 80.1
```


### 1.2 merge(target = {}, ...args) 将数组转成obj
```javascript
import { merge } from '@bianpengfei/utils'

let a = { id: 1, name: '香蕉', pId: null, order: 2 }
let b = { sort: true, name: '卞鹏飞' }
let c = { x: 10, y: 100 }

merge({}, a, b, c)

// output:
// {
//   "id": 1,
//   "name": "卞鹏飞",
//   "pId": null,
//   "order": 2,
//   "sort": true,
//   "x": 10,
//   "y": 100
// }
```

### 1.3 arrayToObj(array = [], PK = '') 将数组转成obj
```javascript
import { arrayToObj } from '@bianpengfei/utils'

const list = [
 {empId: 1, empName: '蔡徐坤'},
 {empId: 2, empName: '小明'}
]

arrayToObj(list, 'empId')
// 输出
{
  1: {empId: 1, empName: '蔡徐坤'},
  2: {empId: 2, empName: '小明'}
}

const list = [1, 2, 3, '4']
arrayToObj(list)
// 输出
{
  1: 1
  2: 2,
  3: 3,
  4: '4'
}
```
