## 1.示例

```js

/* 测试用例 */
;(async () => {
  try {
```

## 2.入参说明

| 参数       | 说明             | 类型             | 是否必填 | 默认值 |

| initValue  | 初始化值         | `Any`            | -        | -      |

## 3.源码

::: details 源码，点开查看 👈

```js
/**
 * 执行异步队列，异步请求函数数组
 * @param {Array<Promise>} asyncTasks
 * @param {*} initValue 初始化值
 * @returns {*}
 */
function queuePromises(asyncTasks, initValue) {
  return asyncTasks.reduce((pre, cur) => pre.then(cur), Promise.resolve(initValue))
}
```
