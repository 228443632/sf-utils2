::: note 描述
判断是否是 ios 平台，返回类型 boolean
:::

## 1.示例

```js
import { isIos } from '@bianpengfei/utils'

isIos() // true 返回类型boolean
```

## 2.入参说明

| 参数 | 说明 | 类型 | 是否必填 |
| ---- | ---- | ---- | -------- |

## 3.源码

```js
/**
 * 判断是否在ios环境中
 * @returns {boolean}
 */
function isIos() {
  return !!navigator.userAgent.match(/\(i[^;]+;( U;)? CPU.+Mac OS X/)
}
```
