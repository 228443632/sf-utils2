::: note 描述
判断是否是在安卓平台，返回会 boolean
:::

## 1.示例

```js
import { isAndroid } from '@bianpengfei/utils'

isAndroid() // false， 返回类型boolean
```

## 2.入参说明

| 参数 | 说明 | 类型 | 是否必填 |
| ---- | ---- | ---- | -------- |

## 3.源码

```js
/**
 * 判断是否在安卓环境
 * @returns {boolean}
 */
function isAndroid() {
  return navigator.userAgent.indexOf('Android') > -1 || navigator.userAgent.indexOf('Adr') > -1
}
```
