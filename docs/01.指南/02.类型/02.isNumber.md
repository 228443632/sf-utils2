::: note 描述
判断数据类型是否是整数, 返回值 boolean
:::

## 1.示例

```js
import { isNumber } from '@bianpengfei/utils'

isNumber('1') // false
isNumber('2s') // false
isNumber(0) // true
isNumber({}) // false
```

## 2.入参说明

| 参数 | 说明 | 类型 | 是否必填 |
| ---- | ---- | ---- | -------- |
| arg  |      | any  | 是       |

## 3.源码

```js
/**
 * 判断是否是数字
 * @param {any} arg
 * @returns {boolean}
 */
function isNumber(arg) {
  return Object.prototype.toString.call(arg) === '[object Number]'
}
```
