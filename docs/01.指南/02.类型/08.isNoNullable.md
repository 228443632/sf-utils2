::: note 描述
判断是否 非 undefined 或 null
:::

## 1.示例

```js
import { isNullable } from '@bianpengfei/utils'

isNullable(null) // false
isNullable(undefined) // false
isNullable('1') // true
isNullable('2s') // true
isNullable(0) // true
isNullable({}) // true
isNullable([1, 2, 3]) // true
isNullable({ name: '@bianpengfei/utils' }) // true
isNullable(() => {}) // true
```

## 2.入参说明

| 参数 | 说明 | 类型 | 是否必填 |
| ---- | ---- | ---- | -------- |
| v    | 参数 | any  | 是       |

## 3.源码

```js
/**
 * 是否 非undefined 或 null
 * @param {any} v
 * @returns {boolean}
 */
function isNoNullable(v) {
  return v !== undefined && v !== null
}
```
