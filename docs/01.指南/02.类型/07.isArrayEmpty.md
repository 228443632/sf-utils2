::: note 描述
判断数组长度是否是 0，空数组, 返回值 boolean
:::

## 1.示例

```js
import { isArrayEmpty } from '@bianpengfei/utils'

isArrayEmpty([]) // true

isArrayEmpty([{}, 1]) // false

isArrayEmpty('12') // false

isArrayEmpty(null) // false

isArrayEmpty(undefined) // false

isArrayEmpty('2s') // false

isArrayEmpty(0) // false

isArrayEmpty({}) // false

isArrayEmpty([1, 2, 3]) // false

isArrayEmpty({ name: '@bianpengfei/utils' }) // false

isArrayEmpty(() => {}) // false
```

## 2.入参说明

| 参数 | 说明 | 类型 | 是否必填 |
| ---- | ---- | ---- | -------- |
| arg  |      | any  | 是       |

## 3.源码

```js
import isArray from './isArray'

/**
 * 判断数组是否为空
 * @param {any} arg
 * @returns {boolean}
 */
function isArrayEmpty(arg) {
  return isArray(arg) && arg.length == 0
}
```
