::: note 描述
确定当前运行时环境是否为浏览器，返回 Boolean
:::

## 1.示例

```js
import { isBrowser } from '@bianpengfei/utils'

isBrowser() // false， 返回类型boolean
```

## 2.入参说明

| 参数 | 说明 | 类型 | 是否必填 |
| ---- | ---- | ---- | -------- |

## 3.源码

```js
/**
 * 判断是否在浏览器环境
 * @type {boolean}
 */
function isBrowser() {
  return typeof window !== 'undefined'
}
```
