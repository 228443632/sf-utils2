::: note 描述
判断数据类型是否是 布尔型, 返回值 boolean
:::

## 1.示例

```js
import { isBoolean } from '@bianpengfei/utils'

isBoolean('1') // false
isBoolean(null) // false
isBoolean(undefined) // true
isBoolean('2s') // false
isBoolean(0) // false
isBoolean({}) // false
isBoolean([1, 2, 3]) // false
isBoolean({ name: '@bianpengfei/utils' }) // false
isBoolean(() => {}) // false
```

## 2.入参说明

| 参数 | 说明 | 类型 | 是否必填 |
| ---- | ---- | ---- | -------- |
| arg  |      | any  | 是       |

## 3.源码

```js
/**
 * 判断是否是boolean
 * @param {any} arg
 * @returns {boolean}
 */
function isBoolean(arg) {
  return Object.prototype.toString.call(arg).slice(8, -1) === 'Boolean'
}
```
