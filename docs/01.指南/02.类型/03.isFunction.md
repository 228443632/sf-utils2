::: note 描述
判断数据类型是否是方法
:::

## 1.示例

```js
import { isFunction } from '@bianpengfei/utils'

function sayHello() {
  alert('hello world')
}

isFunction('1') // false
isFunction('2s') // false
isFunction(0) // false
isFunction({}) // false
isFunction([1, 2, 3]) // false
isFunction({ name: '@bianpengfei/utils' }) // false
isFunction(() => {}) // true
isFunction(sayHello) // true
```

## 2.入参说明

| 参数 | 说明 | 类型 | 是否必填 |
| ---- | ---- | ---- | -------- |
| arg  |      | any  | 是       |

## 3.源码

```js
/**
 * 判断是否是方法
 * @param {any} arg
 * @returns {boolean}
 */
function isFunction(arg) {
  return Object.prototoString.call(arg) === '[object Function]'
}
```
