## 1.示例

### 1.1 isAsyncFunction(arg) 判断是否是异步方法

```javascript
import { isAsyncFunction } from '@bianpengfei/utils'

function sayHello() {
  alert('hello world')
}

async function sayNo() {}

isFunction(sayHello) // false
isFunction('2s') // false
isFunction({}) // false
isFunction({ name: '@bianpengfei/utils' }) // false
isFunction(sayNo) // true
```
