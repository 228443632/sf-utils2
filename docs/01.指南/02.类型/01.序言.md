::: note 描述
这一块主要是对 数据进行校验。
:::

### npm 使用方式

```js
import BUtils, { isObject } from '@bianpengfei/utils'

// 方式一
isObject({})

// 方式二
BUtils.isObject({})
```

### cdn 使用方式

```html
<script src="https://cdn.jsdelivr.net/npm/@bianpengfei/utils/lib/b-utils.min.js"></script>
<script>
  // 方式一
  const { isObject } = window.BUtils
  isObject({})

  // 方式二
  window.BUtils.isObject({})
</script>
```
