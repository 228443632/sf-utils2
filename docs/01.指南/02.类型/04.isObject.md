::: note 描述
判断数据类型是否是对象, 返回值 boolean
:::

## 1.示例

```js
import { isObject } from '@bianpengfei/utils'

isObject('1') // false
isObject('2s') // false
isObject(0) // false
isObject({}) // false
isObject([1, 2, 3]) // false
isObject({ name: '@bianpengfei/utils' }) // true
```

## 2.入参说明

| 参数 | 说明 | 类型 | 是否必填 |
| ---- | ---- | ---- | -------- |
| arg  |      | any  | 是       |

## 3.源码

```js
/**
 * 是否是对象
 * @param {any} arg
 * @returns {boolean}
 */
function isObject(arg) {
  return Object.prototype.toString.call(arg) === '[object Object]'
}
```
