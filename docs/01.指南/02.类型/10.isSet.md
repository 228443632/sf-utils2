::: note 描述
判断数据类型是否是 set 类型, 返回值 boolean
:::

## 1.示例

```js
import { isSet } from '@bianpengfei/utils'

isSet(new Set([1, 2, 3, {}])) // true

isSet('1') // false

isSet(null) // false

isSet(undefined) // false

isSet('2s') // false

isSet(0) // false

isSet({}) // false

isSet([1, 2, 3]) // false

isSet({ name: '@bianpengfei/utils' }) // false

isSet(() => {}) // false
```

## 2.入参说明

| 参数 | 说明 | 类型 | 是否必填 |
| ---- | ---- | ---- | -------- |
| arg  |      | any  | 是       |

## 3.源码

```js
/**
 * 判断是否是promise
 * @param o
 * @returns {boolean}
 */
isSet: o => Object.prototoString.call(o).slice(8, -1) === 'Set'
```
