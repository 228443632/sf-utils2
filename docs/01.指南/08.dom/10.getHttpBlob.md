::: note 描述
通过 ajax 获取远程二进制数据流
:::

## 1.示例

::: demo

```vue
<template>
  <div>
    <el-button @click="onClick">点击获取远程的blob</el-button>
  </div>
</template>

<script>
import { getHttpBlob } from '@bianpengfei/utils'
const url = 'https://info.compassedu.hk/ad/225/1637553399694.png?imageView2/3/q/100|imageslim'
export default {
  methods: {
    async onClick() {
      const blob = await getHttpBlob(url)
      alert('获取远程blob成功，去查看一下控制输出吧')
      console.log('打印一下', blob)
    }
  }
}
</script>
```

:::

| 参数 | 说明          | 类型     | 是否必填 | 默认值 |
| ---- | ------------- | -------- | -------- | ------ |
| url  | http 链接地址 | `String` | 是       |        |

## 3.源码

::: details 源码，点开查看 👈

```js
function getHttpBlob(url) {
  return new Promise((resolve, reject) => {
    const xhr = new XMLHttpRequest()
    xhr.open('GET', url, true)
    xhr.responseType = 'blob'
    xhr.onload = () => {
      if (xhr.status === 200) {
        resolve(xhr.response)
      } else {
        reject(xhr)
      }
    }
    xhr.send()
  })
}
```
