::: note 描述
数组去重
:::

## 1.示例

```js
import { uniq } from '@bianpengfei/utils'

uniq([11, 22, 33, 33, 22, 55]) // [11, 22, 33, 55]

```

## 2.入参说明

| 参数 | 说明 | 类型  | 是否必填 |
| ---- | ---- | ----- | -------- |
| val  | 值   | `Array` | -------- |

## 3.源码

```js
/**
 * 数组去重
 * @param {any} val
 */
function uniq(val = []) {
  return [...new Set(Array.from(val))]
}
```
