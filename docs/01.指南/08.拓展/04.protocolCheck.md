::: note 描述
主要是为了解决从某一浏览器，唤起 pc 端其他客户端应用。
:::

## 1.示例

::: demo

```vue
<template>
  <div class="col-md-9 col-sm-12">
    <el-button @click="onOpenIe">点击打开ie浏览器</el-button>
  </div>
</template>

<script>
import protocolCheck from '@bianpengfei/utils/lib/expand/protocolCheck'

export default {
  data() {
    return {}
  },

  methods: {
    // 打开ie
    onOpenIe() {
      protocolCheck(
        'ie://http://www.baidu.com',
        () => {
          alert('打开失败')
        },
        () => {
          alert('打开成功')
        }
      ),
        () => {
          alert('不支持协议')
        }
    }
  }
}
</script>
```

:::

## 2.入参说明

### 主参数

| 参数          | 说明               | 类型       | 是否必填 | 默认值 |
| ------------- | ------------------ | ---------- | -------- | ------ |
| uri           | 协议地址           | `String`   | 是       | -      |
| failCb        | 失败回调函数       | `Function` | 是       | -      |
| successCb     | 成功回调函数       | `Function` | -        | -      |
| unsupportedCb | 不支持协议回调函数 | `Function` | -        | -      |

## 4.协议自定义注册

### 4.1 ie 注册 ie-open-script.reg

唤起例子：`ie://http://www.baidu.com?id=10`

```shell
Windows Registry Editor Version 5.00

[HKEY_CURRENT_USER\Software\Classes\ie]
"URL Protocol"=""
@="URL:IE Protocol"

[HKEY_CURRENT_USER\Software\Classes\ie\shell]

[HKEY_CURRENT_USER\Software\Classes\ie\shell\open]

[HKEY_CURRENT_USER\Software\Classes\ie\shell\open\command]
@="cmd /c set url=\"%1\" & call set url=%%url:ie://=%% & call start iexplore -nosessionmerging -noframemerging %%url%%"
```
