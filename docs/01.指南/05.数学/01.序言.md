::: note 描述
先让我说一下痛点吧，前端做运算的时候，尤其是对浮点型数值计算进度不准问题。然后你可能自己手写或者找其他轮子。
<br/>
这一块是主要提供数学计算，基于 [decimal.js-light](https://github.com/MikeMcl/decimal.js-light)，详情使用方式请查看 [decimal.js-light](https://github.com/MikeMcl/decimal.js-light)
<br/>
🎉 支持浮点型运算。
<br/>
🎉 提供基础的数据计算，求和、求平均值。
<br/>
🎉 自动对非数字型的转化为 0。
:::

### npm 使用方式

```js
import BUtils, { sum } from '@bianpengfei/utils'

// 方式1
sum(...[1.1, 3, 4, 100.0001]) // 108.1001

// 方式2
BUtils.sum(...[1.1, 3, 4, 100.0001])
```

### cdn 使用方式

```html
<script src="https://cdn.jsdelivr.net/npm/@bianpengfei/utils/lib/b-utils.min.js"></script>
<script>
  window.BUtils.sum(...[1.1, 3, 4, 100.0001]) // 108.1001
</script>
```

::: details 源码，点开查看 👈

```js
/**
 * @Description: 封装基础常用的 计算总和、平均值、除法、乘法
 * @Author bianpengfei
 * @create 2021/12/24 22:45
 */
import Type from './Type'
import Decimal from 'decimal.js-light'

export default {
  Decimal,

  /**
   * 获取总和   sum(...[1, 2, 3])
   * @param args
   * @returns {*}
   */
  sum: (...args) => args.reduce((p, c) => +new Decimal(p).add(c).toFixed(), 0),

  /**
   * 求平均值  avg(...[1, 2, 3])
   * @param args
   * @returns {number}
   */
  avg: function (...args) {
    return +new Decimal(this.sum(...args)).div(args.length).toFixed()
  },

  /**
   * 求arg1 除以 arg2
   * @param arg1
   * @param arg2
   * @returns {number|number}
   */
  div: (arg1, arg2) => {
    return !Type.isNumber(arg2) || isNaN(arg2) || +arg2 == 0 ? 0 : +new Decimal(+arg1 || 0).div(+arg2).toFixed()
  },

  /**
   * 相乘
   * @param arg1
   * @param arg2
   * @returns {number}
   */
  mul: (arg1, arg2) => +new Decimal(+arg1 || 0).mul(+arg2 || 0).toFixed(),

  /**
   * 相加
   * @param arg1
   * @param arg2
   * @returns {number}
   */
  add: (arg1, arg2) => +new Decimal(+arg1 || 0).add(+arg2 || 0).toFixed(),

  /**
   * 获取最大值 max(...[1, 2, 4])
   * @param args
   * @returns {number}
   */
  max: (...args) => Math.max(...args),

  /**
   * 获取最小值 max(...[1, 2, 4])
   * @param args
   * @returns {number}
   */
  min: (...args) => Math.min(...args)
}
```
