::: note 描述
封装一些常见的装饰器。
:::

### npm 使用方式

```js
import BUtils, { debounceDtor } from '@bianpengfei/utils'

// 方式1
@debounceDtor(300)
function onResize() {
  console.log('监听到窗口发生变化')
}
window.addEventListener('resize', onResize, false)

// 方式2
@BUtils.debounceDtor(300)
function onResize() {
  console.log('监听到窗口发生变化')
}
window.addEventListener('resize', onResize, false)
```

::: danger
注意：npm 使用时请配合 babel，浏览器大多数时不支持装饰器，需要安装 [@babel/plugin-proposal-decorators](https://babeljs.io/docs/en/babel-plugin-proposal-decorators#docsNav)
:::

```shell
# yarn安装
yarn add @babel/plugin-proposal-decorators -D

#npm安装
npm i @babel/plugin-proposal-decorators -D
```

- 修改文件 .babelrc 或 babel.config.js

```js
plugins: [['@babel/plugin-proposal-decorators', { legacy: true }]]
```

### cdn 使用方式 不推荐，因为大多数浏览器不支持的，除非你引入 babel 转化器 cdn，但这样意义不大了。
