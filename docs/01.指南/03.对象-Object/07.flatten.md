## 2.入参说明

| 参数 | 说明                   | 类型       | 是否必填 |
| ---- | ---------------------- | ---------- | -------- |
| obj  | 原对象                 | `Obejct`   | 是       |
| cb   | 每次循环之前，回调函数 | `Function` | -        |

## 3.源码

```js
import _helperObjectFlatten from '@/_helper/_helperObjectFlatten'

/**
 * 将对象进行扁平化
 * @param {Object} obj
 * @returns {*}
 */
function flatten(obj) {
  return _helperObjectFlatten(obj)
}

export default flatten
```
