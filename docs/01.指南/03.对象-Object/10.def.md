::: note 描述
定义属性，主要是为了方便定义不可`枚举`的属性值。 <Badge text="v2+" type="success" vertical="middle"/>
:::

## 1.示例

```js
import { def } from 'sf-utils2'

let person = { name: '蔡徐坤' }
def(person, 'age', 100)

Object.keys(person).length // 1
```

## 2.入参说明

| 参数       | 说明             | 类型      | 是否必填 | 默认值    |
| ---------- | ---------------- | --------- | -------- | --------- |
| obj        | 原对象           | `Object`  | 是       |           |
| key        | 字段名【属性名】 | `String`  | 是       |           |
| value      | 值               | `any`     | 否       | undefined |
| enumerable | 是否允许枚举     | `Boolean` | 否       | false     |

## 3.源码

```js
/**
 * 定义属性[不可枚举]
 * @param {Object} obj
 * @param {String} key
 * @param {*} val
 * @param {Boolean} enumerable
 * @returns {*}
 * @example
 *
 * let person = {name: '蔡徐坤'}
 * def(person, 'age', '100')
 */
function def(obj, key, val = undefined, enumerable = false) {
  const attribute = {
    enumerable: !!enumerable,
    writable: true,
    configurable: true
  }
  if (val !== undefined) attribute.value = val
  return Object.defineProperty(obj, key, attribute)
}

export default def
```
