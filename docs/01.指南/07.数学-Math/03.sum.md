::: note 描述
数组中求和。🎉 支持浮点型计算
:::

## 1.示例

```js
import { sum } from 'sf-utils2'

// 浮点型计算累计
sum(...[1.1, 3, 4, 100.3]) // 输出结果 108.4

// 计算累计 1-100的总和
sum(...[...new Array(100)].map((v, vi) => vi + 1)) // 输出结果 5050
```

## 2.入参说明

| 参数 | 说明       | 类型     | 是否必填 | 默认值 |
| ---- | ---------- | -------- | -------- | ------ |
| args | 不确定参数 | `Number` |          |        |

## 3.源码

```js
import Decimal from './Decimal'

/**
 * 获取总和   sum(...[1, 2, 3])
 * @param args
 * @returns {*}
 */
function sum(...args) {
  return args.reduce((p, c) => +new Decimal(p).add(c).toFixed(), 0)
}
```
