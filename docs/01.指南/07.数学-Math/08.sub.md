::: note 描述
减法，两数字相减，🎉 支持浮点型计算
⚠️ 非数字的值全都当作 `0` 处理
:::

## 1.示例

```js
import BUtils from '@bianpengfei/utils'

console.log(BUtils.sub(0.3, 0.8)) // 输出结果 -0.5

console.log(BUtils.sub(1.222, 8)) // 输出结果 -6.778

console.log(BUtils.sub(1, 0)) // 输出结果 1

console.log(BUtils.sub('12342s', 1.1)) // 输出结果 -1.1
```

## 2.入参说明

| 参数 | 说明       | 类型     | 是否必填 | 默认值 |
| ---- | ---------- | -------- | -------- | ------ |
| arg1 | 数字参数 1 | `Number` | 是       |        |
| arg2 | 数字参数 1 | `Number` | 是       |        |

## 3.源码

```js
import Decimal from './Decimal'

/**
 * 相减去
 * @param arg1
 * @param arg2
 * @returns {number}
 */

function sub(arg1, arg2) {
  return +new Decimal(+arg1 || 0).sub(+arg2 || 0).toFixed()
}
```
