::: note 描述
除法，两数字相除，🎉 支持浮点型计算
⚠️ 当分母是 0 或非数字型，返回值统一为 0
:::

## 1.示例

```js
import { div } from 'sf-utils2'

// 浮点型计算
div(0.3, 0.8) // 输出结果 0.375

// 计算 1 除以 8
div(1, 8) // 输出结果 0.125

// 计算 1 除以 0
div(1, 0) // 输出结果 0

// 计算 1 除以 非数字型的
div(1, '12342s') // 输出结果 0
```

## 2.入参说明

| 参数 | 说明 | 类型     | 是否必填 | 默认值 |
| ---- | ---- | -------- | -------- | ------ |
| arg1 | 分子 | `Number` | 是       |        |
| arg2 | 分母 | `Number` | 是       |        |

## 3.源码

```js
import Decimal from './Decimal'
import isNumber from '@/base/isNumber'

/**
 * 求arg1 除以 arg2
 * @param arg1
 * @param arg2
 * @returns {number|number}
 */
function div(arg1, arg2) {
  return !isNumber(arg2) || isNaN(arg2) || +arg2 == 0 ? 0 : +new Decimal(+arg1 || 0).div(+arg2).toFixed()
}

export default div
```
