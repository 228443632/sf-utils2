::: note 描述
数组中算平均值。🎉 支持浮点型计算
:::

## 1.示例

```js
import { avg } from 'sf-utils2'

// 浮点型计算
avg(...[1.1, 3, 4, 100.3]) // 输出结果 27.1

// 计算累计 1-100的平均值
avg(...[...new Array(100)].map((v, vi) => vi + 1)) // 输出结果 50.5
```

## 2.入参说明

| 参数 | 说明       | 类型     | 是否必填 | 默认值 |
| ---- | ---------- | -------- | -------- | ------ |
| args | 不确定参数 | `Number` |          |        |

## 3.源码

```js
/**
 * 求平均值  avg(...[1, 2, 3])
 * @param args
 * @returns {number}
 */
function avg(...args) {
  return +new Decimal(sum(...args)).div(args.length).toFixed()
}
```
