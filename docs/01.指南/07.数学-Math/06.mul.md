::: note 描述
乘法，两数字相乘，🎉 支持浮点型计算
⚠️ 当两数 只要其中有一个非数字型，将返回结果 0
:::

## 1.示例

```js
import { mul } from 'sf-utils2'

// 浮点型计算
mul(0.3, 0.8) // 输出结果 0.24

// 计算 1 乘以 8
mul(1, 8) // 输出结果 8

// 计算 1 乘以 0
mul(1, 0) // 输出结果 0

// 计算 1 乘以 非数字型的
mul(1, '12342s') // 输出结果 0
```

## 2.入参说明

| 参数 | 说明       | 类型     | 是否必填 | 默认值 |
| ---- | ---------- | -------- | -------- | ------ |
| arg1 | 数字参数 1 | `Number` | 是       |        |
| arg2 | 数字参数 1 | `Number` | 是       |        |

## 3.源码

```js
import Decimal from './Decimal'

/**
 * 相乘
 * @param arg1
 * @param arg2
 * @returns {number}
 */
function mul(arg1, arg2) {
  return +new Decimal(+arg1 || 0).mul(+arg2 || 0).toFixed()
}
```
