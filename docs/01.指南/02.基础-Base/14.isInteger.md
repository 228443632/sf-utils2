::: note 描述
判断数据类型是否是整数, 返回值 boolean
:::

## 1.示例

```js
import { isInteger } from 'sf-utils2'

isInteger(null) // false
isInteger(3.3) // false
isInteger(3) // true
isInteger(0) // true
```

## 2.入参说明

| 参数 | 说明 | 类型 | 是否必填 |
| ---- | ---- | ---- | -------- |
| val  |      | any  | 是       |

## 3.源码

```js
import isNumber from './isNumber'

/**
 * 判断是否整数
 * @param {any} val
 */
function isInteger(val) {
  return isNumber(val) && val % 1 === 0
}
```
