::: note 描述
判断数据类型是否是 set 类型, 返回值 boolean
:::

## 1.示例

```js
import { isSet } from 'sf-utils2'

isSet(new Set([1, 2, 3, {}])) // true
isSet('1') // false
isSet(null) // false
isSet(undefined) // false
isSet('2s') // false
isSet(0) // false
isSet({}) // false
isSet([1, 2, 3]) // false
isSet({ name: 'sf-utils2' }) // false
isSet(() => {}) // false
```

## 2.入参说明

| 参数 | 说明 | 类型 | 是否必填 |
| ---- | ---- | ---- | -------- |
| val  |      | any  | 是       |

## 3.源码

```js
import _typeof from '@/type/_typeof'

/**
 * 判断是否是promise
 * @param {any} val
 * @returns {boolean}
 */
function isSet(val) {
  return _typeof(val) === 'Set'
}
```
