::: note 描述
判断数据类型是否是 布尔型, 返回值 boolean
:::

## 1.示例

```js
import { isBoolean } from 'sf-utils2'

isBoolean('1') // false
isBoolean(null) // false
isBoolean(undefined) // false
isBoolean(false') // true
isBoolean(0) // false
isBoolean({}) // false
isBoolean([1, 2, 3]) // false
isBoolean({ name: 'sf-utils2' }) // false
isBoolean(() => {}) // false
```

## 2.入参说明

| 参数 | 说明 | 类型 | 是否必填 |
| ---- | ---- | ---- | -------- |
| val  |      | any  | 是       |

## 3.源码

```js
import _typeof from '@/type/_typeof'

/**
 * 判断是否是boolean
 * @param {any} val
 * @returns {boolean}
 */
function isBoolean(val) {
  return _typeof(val) === 'Boolean'
}
```
