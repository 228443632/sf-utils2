返回数据类型
:::

## 1.示例

```js
import { _typeof } from 'sf-utils2'

_typeof('') // String
_typeof(null) // Null
_typeof({}) // Object
_typeof(Promise.resolve()) // Promise
_typeof([]) // Array
_typeof(new Set([])) // Set
_typeof(new Map([[1, () => {}]])) // Map
_typeof(0) // Number
_typeof(0.22) // Number
_typeof(new Date()) // Date
_typeof(window.cccc) // Undefined
```

## 2.入参说明

| 参数 | 说明 | 类型 | 是否必填 |
| ---- | ---- | ---- | -------- |
| args |      | any  | 是       |
