::: note 描述
获取一个全局唯一标识
:::

## 1.示例

```js
import { uniqueId } from '@bianpengfei/utils'

uniqueId() // 1
uniqueId() // 2
uniqueId('prefix_') // 'prefix_3'
                
```

## 2.入参说明

| 参数     | 说明 | 类型            | 是否必填 | 默认值  |
|--------|--| --------------- | -------- | ------- |
| prefix | 前缀 | String             | -        | -       |

## 3.源码

```js
/**
 * 获取一个全局唯一标识
 *
 * @param {String} prefix 前缀
 * @return {String}
 */
let __uniqueId = 0
function uniqueId(prefix) {
  return [prefix, ++__uniqueId].join('')
}
```
