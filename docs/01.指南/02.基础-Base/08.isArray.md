::: note 描述
判断是否是 null 或 undefined
:::

## 1.示例

```js
import { isArray } from '@bianpengfei/utils'

isArray(null) // false
isArray({}) // false
isArray([1,2,3]) // true
```

## 2.入参说明

| 参数 | 说明 | 类型 | 是否必填 |
| ---- | ---- | ---- | -------- |
| val  | 参数 | any  | 是       |

## 3.源码

```js
import _typeof from '@/base/_typeof'

/**
 * 判断是否是array 数组
 * @param val
 * @returns {boolean}
 */
function isArray(val) {
  return Array.isArray ? Array.isArray(val) : _typeof(val) === 'Array'
}
```
