::: note 描述
判断数据类型是否是 Object 对象, 返回值 boolean
:::

## 1.示例

```js
import { isObject } from 'sf-utils2'

isObject('1') // false
isObject('2s') // false
isObject(0) // false
isObject([1, 2, 3]) // true
isObject({ name: 'sf-utils2' }) // true
isObject(null) // true
isObject([]) // true
isObject({}) // true
isObject(123) // false
```

## 2.入参说明

| 参数 | 说明 | 类型 | 是否必填 |
| ---- | ---- | ---- | -------- |
| val  |      | any  | 是       |

## 3.源码

```js
/**
 * 是否 Object 对象
 * @param {any} val
 * @returns {boolean}
 */
function isPlainObject(val) {
  return val !== null && typeof val === 'object'
}

export default isPlainObject
```
