::: note 描述
判断数据类型是否是`Number`类型, 返回值 boolean，: 要排除 Infinity, -Infinity, 以及 NaN 数值类型，等价于`lodash`的`isFinite`方法
:::

## 1.示例

```js
import { isNumber } from 'sf-utils2'

isNumber(NaN) // false
isNumber(Infinity) // false
isNumber(-Infinity) // false
isNumber('1') // false
isNumber('2s') // false
isNumber(0) // true
isNumber({}) // false
```

## 2.入参说明

| 参数 | 说明 | 类型 | 是否必填 |
| ---- | ---- | ---- | -------- |
| val  |      | any  | 是       |

## 3.源码

```js
import _typeof from '@/type/_typeof'

/**
 * 判断是否是数字 合法的
 * @param {any} val
 * @returns {boolean}
 */
function isNumber(val) {
  return _typeof(val) === 'Number' && !isNaN(val) && val !== Infinity && val !== -Infinity
}
```
