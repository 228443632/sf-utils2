::: note 描述
解析 URL 中的查询参数和 Hash 参数，并分别返回 params 和 hash 对象 <Badge text="3.3.6-beta.3+" type="success" vertical="middle"/>
:::

## 1.示例

```js
import { parseURLIncludeHash } from 'sf-utils2'

parseURLIncludeHash('google.com')
// { hash: {}, params: {} }

parseURLIncludeHash('http://url.com/page?name=Adam&surname=Smith#/home?id=1&token=abc')
// {
//   params: { name: 'Adam', surname: 'Smith' },
//   hash: { id: '1', token: 'abc' }
// }
```

## 2.入参说明

| 参数 | 说明     | 类型     | 是否必填 |
| ---- | -------- | -------- | -------- |
| url  | url 地址 | `string` | 是       |

## 3.返回值说明

| 返回值 | 说明                     | 类型                     |
| ------ | ------------------------ | ------------------------ |
| hash   | Hash 部分的查询参数对象  | `Record<string, string>` |
| params | URL 查询字符串的参数对象 | `Record<string, string>` |

## 4.源码

```ts
/**
 * @Description:
 * @Author 卞鹏飞 <228443632@qq.com>
 * @create 2026/5/8 23:08
 */

import getGlobalThis from 'sf-utils2/base/getGlobalThis'
import isNode from '@/base/isNode'

/**
 * 解析URL Hash
 * @param url
 */
function parseURLIncludeHash(url: string) {
  if (url) {
    const globalThis = getGlobalThis() as typeof global
    let base: string
    if (!/^http/.test(url)) base = isNode() ? 'http://localhost:3000' : globalThis.origin
    // @ts-ignore
    const urlInstance = new globalThis.URL(url, base)
    const hashString = urlInstance.hash.split('?').filter(Boolean)[1] || ''
    const hashSearchParams = new globalThis.URLSearchParams(hashString)
    const historySearchParams = urlInstance.searchParams
    return {
      hash: Object.fromEntries(hashSearchParams),
      params: Object.fromEntries(historySearchParams)
    }
  }
  return {
    hash: {},
    params: {}
  }
}

export default parseURLIncludeHash
```
