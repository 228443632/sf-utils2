::: note 描述
解析 URL 参数作为对象
:::

## 1.示例

```js
import { parseURL } from 'sf-utils2'

parseURL('google.com') // {}
parseURL('http://url.com/page?name=Adam&surname=Smith')
// {name: 'Adam', surname: 'Smith'}
```

## 2.入参说明

| 参数 | 说明     | 类型     | 是否必填 |
| ---- | -------- | -------- | -------- |
| url  | url 地址 | `string` | 是       |

## 3.源码

```js
/**
 * 解析获取Url
 * @param url
 * @returns {{}}
 */
function parseURL(url = '') {
  return (url.match(/([^?=&]+)(=([^&]*))/g) || []).reduce(
    (a, v) => ((a[v.slice(0, v.indexOf('='))] = v.slice(v.indexOf('=') + 1)), a),
    {}
  )
}
```
