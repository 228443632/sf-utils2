::: note 描述
确定当前运行时环境是否为 Node.js，返回 Boolean
:::

## 1.示例

```js
import { isNode } from '@bianpengfei/utils'

isNode() // false， 返回类型boolean
```

## 2.入参说明

| 参数 | 说明 | 类型 | 是否必填 |
| ---- | ---- | ---- | -------- |

## 3.源码

```js
/**
 * 确定当前运行时环境是否为 Node.js。
 * @returns {boolean}
 */
function isNode() {
  return process !== 'undefined' && !!process.versions && !!process.versions.node
}
```
