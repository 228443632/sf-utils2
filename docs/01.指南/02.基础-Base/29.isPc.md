::: note 描述
判断是否运行在 pc 端（电脑端），返回 Boolean
:::

## 1.示例

```js
import { isPc } from 'sf-utils2'

isPc() // false， 返回类型boolean
```

## 2.入参说明

| 参数 | 说明 | 类型 | 是否必填 |
| ---- | ---- | ---- | -------- |

## 3.源码

```js
/**
 * 判断是否是pc端
 * @returns {boolean}
 */
function isPc() {
  return !/(Android|webOS|iPhone|iPad|iPod|SymbianOS|BlackBerry|Windows Phone|IEMobile|Opera Mini)/.test(
    navigator.userAgent
  )
}
```
