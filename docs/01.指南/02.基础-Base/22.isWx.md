::: note 描述
判断是否在微信环境中, 返回值 boolean
:::

## 1.示例

```js
import { isWx } from 'sf-utils2'

isWx()
```

## 2.入参说明

| 参数 | 说明 | 类型 | 是否必填 |
| ---- | ---- | ---- | -------- |

## 3.源码

```js
/**
 * 判断是否在微信中
 * @returns {boolean}
 */
function isWx() {
  return navigator.userAgent.toLowerCase().match(/MicroMessenger/i) == 'micromessenger'
}
```
