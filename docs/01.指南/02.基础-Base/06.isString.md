::: note 描述
判断数据类型是否是字符串, 返回值 boolean
:::

## 1.示例

```js
import { isString } from '@bianpengfei/utils'

isString('1') // true
isString('2s') // true
isString(0) // false
isString({}) // false
isString([1, 2, 3]) // false
isString({ name: '@bianpengfei/utils' }) // false
isString(() => {}) // false
```

## 2.入参说明

| 参数 | 说明 | 类型 | 是否必填 |
| ---- | ---- | ---- | -------- |
| val  |      | any  | 是       |

## 3.源码

```js
import _typeof from '@/type/_typeof'

/**
 * 是否是字符串
 * @param {any} val
 * @returns {boolean}
 */
function isString(val) {
  return _typeof(val) === 'String'
}
```
