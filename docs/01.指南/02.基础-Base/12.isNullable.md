::: note 描述
判断是否是 null 或 undefined
:::

## 1.示例

```js
import { isNullable } from '@bianpengfei/utils'

isNullable(null) // true
isNullable(undefined) // true
isNullable('1') // false
isNullable('2s') // false
isNullable(0) // false
isNullable({}) // false
isNullable([1, 2, 3]) // false
isNullable({ name: '@bianpengfei/utils' }) // false
isNullable(() => {}) // false
```

## 2.入参说明

| 参数 | 说明 | 类型 | 是否必填 |
| ---- | ---- | ---- | -------- |
| val  | 参数 | any  | 是       |

## 3.源码

```js
/**
 * 判断是否是 null或undefined
 * @param {any} val
 * @returns {boolean}
 */
function isNullable(val) {
  return val === undefined || val === null
}
```
