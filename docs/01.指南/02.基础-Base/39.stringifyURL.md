::: note 描述
加工 URL，将 query 参数合并到 URL 上
:::

## 1.示例

```js
import { stringifyURL } from 'sf-utils2'

stringifyURL('http://www.baidu.com?id=123', { id: '22', name: 'haha' })
// 输出 http://www.baidu.com?id=22&name=haha

stringifyURL('http://www.baidu.com#/home', { id: '123' }, { isSearchParamAfterHash: true })
// 输出 http://www.baidu.com#/home?id=123
```

## 2.入参说明

| 参数    | 说明                                            | 类型                             | 是否必填       |
| ------- | ----------------------------------------------- | -------------------------------- | -------------- | --- |
| url     | URL 地址                                        | `string`                         | 是             |
| query   | 需要合并到 URL 上的参数对象                     | `{[key:string                    | symbol]: any}` | 否  |
| options | 选项配置，如果为 boolean 类型则表示是否深度合并 | `TStringifyURLOption \| boolean` | 否             |

### options 配置项

| 参数                   | 说明                                  | 类型      | 默认值  |
| ---------------------- | ------------------------------------- | --------- | ------- |
| isDeepMerge            | 是否深度合并参数                      | `boolean` | `true`  |
| isSearchParamAfterHash | 是否将 query 参数合并到 hash 参数之后 | `boolean` | `false` |

## 3.源码

```js

 * 加工url，将query参数合并到url上

 * @return {string|undefined}
 * @example
 * stringifyURL('http://www.baidu.com?id=123', {id: '22', name: 'haha'})
 * // 输出 http://www.baidu.com?id=22&name=haha

  options$2.isSearchParamAfterHash ??= false

  const urlInstance = new globalThis.URL(url)

    pre[k] = decodeURIComponent(v)
    return pre

    urlInstance.searchParams.set(k, v)

  }
  return resultUrl
}
```
