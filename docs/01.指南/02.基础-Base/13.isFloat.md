::: note 描述
判断数据类型是否是浮点数字, 返回值 boolean
:::

## 1.示例

```js
import { isFloat } from '@bianpengfei/utils'

isFloat(null) // false
isFloat(0) // false
isFloat(3) // false
isFloat(3.3) // true
```

## 2.入参说明

| 参数 | 说明 | 类型 | 是否必填 |
| ---- | ---- | ---- | -------- |
| val  |      | any  | 是       |

## 3.源码

```js
import isNumber from './isNumber'

/**
 * 判断是否小数
 * @param {any} val
 */
function isFloat(val) {
  return isNumber(val) && val % 1 !== 0
}
```
