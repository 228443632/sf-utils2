::: note 描述
判断是否运行在手机端（移动端），返回 Boolean
:::

## 1.示例

```js
import { isMobile } from 'sf-utils2'

isMobile() // false， 返回类型boolean
```

## 2.入参说明

| 参数 | 说明 | 类型 | 是否必填 |
| ---- | ---- | ---- | -------- |

## 3.源码

```js
/**
 * 判断是否是移动端
 * @returns {this is string[]}
 */
function isMobile() {
  return /(Android|webOS|iPhone|iPad|iPod|SymbianOS|BlackBerry|Windows Phone)/.test(navigator.userAgent)
}
```
