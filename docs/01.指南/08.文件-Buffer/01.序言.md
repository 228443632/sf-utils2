::: note 描述
时隔了接近两年更新了一个大版本，该章主要内容是关于浏览器的二进制流转化 `Blob`、`File`、`ArrayBuffer`、`Uint8Array`、`TextEncoder`、`TextDecoder`、`Base64` 之间相互转化

注意：该版本主要针对 `Blob`、`File`、`ArrayBuffer`、`Uint8Array`、`TextEncoder`、`TextDecoder`、`Base64` between convert，
暂不支持 `Nodejs`环境使用，后面考虑支持`nodejs`
:::

### npm 使用方式

```js
import { arrayBufferToBase64 } from 'sf-utils2'

const arrayBuffer = new ArrayBuffer(10)
const base64 = await arrayBufferToBase64(arrayBuffer)
```

### cdn 使用方式

```html
<script src="https://cdn.jsdelivr.net/npm/sf-utils2/lib/b-utils.min.js"></script>
<script></script>
```
