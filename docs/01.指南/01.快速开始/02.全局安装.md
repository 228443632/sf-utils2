## 安装

### 1、npm 安装

采用 npm/yarn 安装，希望配合 webpack 或 vite 进行使用

- node: 12.10+

<code-group>
  <code-block title="YARN" active>
  ```bash
  yarn add @bianpengfei/utils
  ```
  </code-block>

  <code-block title="NPM">
  ```bash
  npm i @bianpengfei/utils
  ```
  </code-block>
</code-group>

### 2、cdn 方式引入

```js
<!-- 引入js -->
<script src="https://cdn.jsdelivr.net/npm/@bianpengfei/utils/lib/index.umd.min.js"></script>
```

::: note 建议
我们建议使用 CDN 引入 @bianpengfei/utils 的用户在链接地址上锁定版本，以免将来 @bianpengfei/utils 升级时受到非兼容性更新的影响。锁定版本的方法请查看
[https://www.jsdelivr.com/](https://www.jsdelivr.com/)
:::

## 为什么选择 @bianpengfei/utils

- 体积小，支持按需加载
- 放开现在任何工具库，暂时还没提供丰富的对递归一些数据转化的方法，这个非常适用于前端开发对接权限信息时或者其他业务场景中用到。比如遇到后端偏懒，只返回一层的
  数据结构，并没有返回想要的数据结构，要么后端做处理，要么前端擦屁股。
- 对平时用到的 webpack、vite 等主流的工程化项目，提供自动注入文件。
- 提供便捷、准确的数据类型判断
  - 丰富的 dom 基础操作方法。
