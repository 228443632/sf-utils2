::: note 如果您使用了 babel，借助插件 babel-plugin-import 可以实现按需加载模块，减少文件体积。
:::

<code-group>
  <code-block title="YARN" active>
  ```bash
  yarn add babel-plugin-import -D
  ```
  </code-block>

  <code-block title="NPM">
  ```bash
  npm i babel-plugin-import -D
  ```
  </code-block>
</code-group>

<br/>

- 修改文件 .babelrc 或 babel.config.js

<code-group>
  <code-block title=".babelrc" active>
  ```json
    {
      "plugins": [
        [
          "import",
          {
            "libraryName": "@bianpengfei/utils",
            "camel2DashComponentName": false
          },
          "@bianpengfei/utils"
        ]
      ]
    }
  ```
  </code-block>

  <code-block title="babel.config.js">
  ``` js
    module.exports = {
      presets: ...,
      env: {
        ...
      },
      plugins: [
        // 注意⚠️：写在这
        [
          'import',
          {
            libraryName: '@bianpengfei/utils',
            camel2DashComponentName: false
          },
          '@bianpengfei/utils'
        ]
      ]
    }
  ```
  </code-block>
</code-group>
