::: note 描述
首字母大写
:::

## 1.示例

```js
import { capitalize } from '@bianpengfei/utils'

capitalize('user-name') // 结果：UserName
capitalize('hello-world_name') // 结果：Hello-world_name
capitalize('cell_item') // 结果：Cell_item
capitalize('USER_ITEM') // 结果：USER_ITEM
```

## 2.入参说明

| 参数 | 说明           | 类型     | 是否必填 | 默认值 |
| ---- | -------------- | -------- | -------- | ------ |
| str  | 要调整的字符串 | `String` | -        | -      |

## 3.源码

::: details 源码，点开查看 👈

```js
import isString from '@/base/isString.js'

/**
 * 首字母大写
 * @param {String}  str
 * @returns {string|*}
 */
function capitalize(str) {
  if (!isString(str)) return str
  return str.charAt(0).toUpperCase() + str.slice(1)
}

export default capitalize
```
