## 1.示例

```js
import { escapeHTML } from '@bianpengfei/utils'

escapeHTML(`<div><input/>测试</div>`) => &lt;div&gt;&lt;input/&gt;测试&lt;/div&gt;
```

## 2.入参说明

| 参数 | 说明          | 类型     | 是否必填 | 默认值 |
| ---- |-------------| -------- | -------- | ------ |
| str  | 要调整的html字符串 | `String` | -        | -      |

## 3.源码

::: details 源码，点开查看 👈

```js
function escapeHTML(str) {
  return str.replace(
    /[&<>'"]/g,
    tag =>
      ({
        '&': '&amp;',
        '<': '&lt;',
        '>': '&gt;',
        "'": '&#39;',
        '"': '&quot;'
      }[tag] || tag)
  )
}

export default escapeHTML
```
