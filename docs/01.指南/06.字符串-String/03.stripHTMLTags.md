## 1.示例

```js

stripHTMLTags(`<div><input/>测试</div>`) => 测试
```

## 2.入参说明

| 参数 | 说明      | 类型     | 是否必填 | 默认值 |
| ---- |---------| -------- | -------- | ------ |
| str  | html字符串 | `String` | -        | -      |

## 3.源码

::: details 源码，点开查看 👈

```js
/**
 * 删除字符串中的HTMl标签
 * @param {String} str
 * @return {*}
 * @example
 * stripHTMLTags(`<div>234242<i>---</i>></div>`) => 234242--->
 */
function stripHTMLTags(str) {
  return str.replace(/<[^>]*>/g, '')
}

export default stripHTMLTags
```
