protocolCheck【协议检测】

描述

主要是为了解决从某一浏览器，唤起 pc 端其他客户端应用。

# 1.示例

点击打开ie浏览器
<template>
  <div class="col-md-9 col-sm-12">
    <el-button @click="onOpenIe">点击打开ie浏览器</el-button>
  </div>
</template>

<script>
import protocolCheck from 'sf-utils2/lib/expand/protocolCheck'

export default {
  data() {
    return {}
  },

  methods: {
    // 打开ie
    onOpenIe() {
      protocolCheck(
        'ie://http://www.baidu.com',
        () => {
          alert('打开失败')
        },
        () => {
          alert('打开成功')
        }
      ),
        () => {
          alert('不支持协议')
        }
    }
  }
}
</script>

# 主参数

参数 说明 类型 是否必填 默认值

successCb 成功回调函数 Function - -
