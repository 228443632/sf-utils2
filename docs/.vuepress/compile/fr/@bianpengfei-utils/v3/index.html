sf-utils2

🚀为简化开发而生

快速开始

优势？

体积小，压缩后仅有48kb，开启gzip仅9.8kb，支持按需加载。

效率至上

只需简单配置，基于实际的前端场景封装常用的方法，从而节省大量时间。

丰富性

内置支持js数据结构转化、dom便捷操作、数学方法封装。
