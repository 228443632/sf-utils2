upperCamelCase【大驼峰命名】

描述

将字符串转成大驼峰命名 v3.0.26+

# 1.示例

import { upperCamelCase } from 'sf-utils2'

upperCamelCase('user-name') // 结果：UserName
upperCamelCase('hello-world_name') // 结果：HelloWorldName
upperCamelCase('cell_item') // 结果：CellItem
upperCamelCase('USER_ITEM') // 结果：USERITEM
upperCamelCase('bianpeng_fei') // 结果：BianpengFei

# 2.入参说明

参数 说明 类型 是否必填 默认值

# 3.源码

源码，点开查看 👈 
import camelCase from "@/string/camelCase";
import capitalize from "@/string/capitalize";

/**
 * 大驼峰命名
 * @param {string} str
 * @return {string}
 */
function upperCamelCase(str) {
	return capitalize(camelCase(str))
}

export default upperCamelCase
